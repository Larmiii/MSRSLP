# Unified environment for training + SLP generation + SLRTP-canonical evaluation.
# Python 3.14, validated on Windows + RTX 4090 (CUDA 12.8).
#
# Install torch from the PyTorch CUDA index (cu128 wheel is required for Py 3.14 — the
# default PyPI wheel is CPU-only and will silently fall back). The CUDA index does not
# carry Py 3.14 wheels for cu121/cu124, so cu128 is the choice here.
#
#     pip install -r requirements.txt \
#         --extra-index-url https://download.pytorch.org/whl/cu128
#
# Or, for CPU-only (no GPU training):
#
#     pip install -r requirements.txt
#     # then `pip install torch torchvision` from default PyPI
#
# If the cu128 wheel download is slow, fetch the .whl manually and `pip install <path>`.
#
# Blackwell GPUs (RTX 50-series, sm_120) REQUIRE the cu128 wheel even on Py 3.11-3.13.
# `--extra-index-url` is only a *fallback* source, so pip may still resolve the CPU wheel
# from default PyPI (torch.cuda.is_available() -> False). Force the GPU wheel explicitly:
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# Validated on Windows 11 + RTX 5090 + Python 3.12 -> torch 2.11.0+cu128.
